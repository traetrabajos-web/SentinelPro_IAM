2.1 Diagrama de Secuencia: Reserva Online y Validación de Disponibilidad

sequenceDiagram
    autonumber
    actor Cliente as 👤 Cliente (Web)
    participant UI as 🌐 Frontend Portal Web
    participant SlotEngine as ⏱️ Motor de Disponibilidad
    participant BookingAPI as 📅 Controlador de Reservas
    participant DB as 🗄️ Base de Datos

    Cliente->>UI: Selecciona Servicio (45 min) y Profesional
    Cliente->>UI: Elige Fecha en el Calendario
    UI->>SlotEngine: Solicita Horarios Disponibles (Servicio, Prof, Fecha)
    SlotEngine->>DB: Consulta jornada, descansos, bloqueos y citas activas
    DB-->>SlotEngine: Retorna jornada y citas ocupadas
    SlotEngine->>SlotEngine: Filtra bloques libres sin solapamiento
    SlotEngine-->>UI: Retorna Slots Libres ["09:00", "09:45", "11:30", "15:00"]
    UI-->>Cliente: Muestra botones de horarios disponibles

    Cliente->>UI: Elige "11:30", completa Nombre/Teléfono y confirma
    UI->>BookingAPI: Envía solicitud de creación de reserva
    BookingAPI->>DB: Verifica disponibilidad atómica del bloque 11:30-12:15
    BookingAPI->>DB: Busca/Actualiza ficha del Cliente por Teléfono (CRM)
    BookingAPI->>DB: Inserta Cita con código único "RES-7391"
    DB-->>BookingAPI: Confirmación exitosa
    BookingAPI-->>UI: Retorna Ticket Digital + Código "RES-7391"
    UI-->>Cliente: Muestra comprobante y botón de confirmación WhatsApp

2.2 Diagrama de Secuencia: Cobro en Caja y Cálculo de Comisión (Panel Admin)

sequenceDiagram
    autonumber
    actor Admin as 👨‍💼 Admin / Recepción
    participant Dashboard as 📊 Panel Administrativo
    participant FinanceSvc as 💰 Servicio de Caja y Comisiones
    participant DB as 🗄️ Base de Datos

    Admin->>Dashboard: Selecciona cita "RES-7391" en la Agenda del Día
    Admin->>Dashboard: Marca estado "EN_ATENCION" al ingresar el cliente
    Dashboard->>DB: UPDATE CITAS SET estado = 'EN_ATENCION'
    Admin->>Dashboard: Pulsa "Finalizar y Cobrar Turno"
    Dashboard-->>Admin: Abre Modal de Caja con Subtotal precargado
    Admin->>Dashboard: Elige método de pago y confirma cobro
    Dashboard->>FinanceSvc: Procesar cobro de cita
    FinanceSvc->>DB: Consulta % de comisión del Profesional
    FinanceSvc->>FinanceSvc: Calcula Comisión del Profesional y Ganancia Neta del Local
    FinanceSvc->>DB: 1. Registra Pago 2. Cita -> COMPLETADA 3. Suma LTV al Cliente
    DB-->>FinanceSvc: OK
    FinanceSvc-->>Dashboard: Actualiza KPIs e Ingresos del Día en vivo

2.3 Diagrama de Máquina de Estados: Ciclo de Vida de una Cita

stateDiagram-v2
    [*] --> PENDIENTE : Reserva Web (Con aprobación manual)
    [*] --> CONFIRMADA : Reserva Web (Auto-confirmada) o Walk-In

    PENDIENTE --> CONFIRMADA : Recepción aprueba turno
    PENDIENTE --> CANCELADA : Cliente o Admin cancela

    CONFIRMADA --> EN_ATENCION : Check-in en el local
    CONFIRMADA --> CANCELADA : Cancelada con código antes del límite
    CONFIRMADA --> NO_ASISTIO : Cliente no se presenta al turno

    EN_ATENCION --> COMPLETADA : Servicio terminado + Cobro en Caja

    COMPLETADA --> [*] : Calcula Comisión + Habilita Reseña
    CANCELADA --> [*] : Libera el horario inmediatamente
    NO_ASISTIO --> [*] : Incrementa alerta en CRM del cliente

4.1 Flujo Algorítmico del Motor de Disponibilidad (Anti-Solapamiento)

flowchart TD
    Start(["🚀 Inicio: Solicitud de Horarios Libres"]) --> GetServ["Obtener duracion_minutos del Servicio"]
    GetServ --> GetSchedule["Consultar HORARIOS_PROFESIONAL del día seleccionado"]
    GetSchedule --> IsWorkDay{"¿El profesional trabaja ese día?"}
    IsWorkDay -- "No" --> ReturnEmpty["Retornar Lista Vacía []"]
    IsWorkDay -- "Sí" --> LoadBusy["Cargar rangos ocupados:
1. Hora de almuerzo
2. Bloqueos especiales
3. Citas activas del día"]
    LoadBusy --> InitPointer["Puntero T_actual = hora_inicio_jornada"]
    InitPointer --> LoopCond{"¿T_actual + duracion <= hora_fin_jornada?"}
    LoopCond -- "No" --> ReturnSlots(["✅ Retornar Lista de Horarios Disponibles"])
    LoopCond -- "Sí" --> CheckOverlap{"¿El bloque [T_actual, T_actual + duracion]
se cruza con algún rango ocupado?"}
    CheckOverlap -- "Sí (Ocupado)" --> StepNext["Avanzar T_actual + 30 min"]
    CheckOverlap -- "No (Libre)" --> AddSlot["Agregar T_actual a Disponibles"]
    AddSlot --> StepNext
    StepNext --> LoopCond
